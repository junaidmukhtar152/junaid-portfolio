# Junaid Mukhtar — Developer Portfolio

A responsive dark-themed React portfolio built with Vite, custom CSS animations and Lucide icons.

## Run locally

1. Install Node.js (LTS recommended).
2. Extract this project and open the folder in VS Code.
3. Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing — personalize these details

- In `src/App.jsx`, replace `YOUR_EMAIL@example.com` in both email links with your real email address.
- Add your LinkedIn profile URL if you want it shown.
- Review the project descriptions and links, especially the live Expense Tracker URL, before sharing publicly.
- Add screenshots of your projects later to make the work section even stronger.

## Build for deployment

```bash
npm run build
```

Vite creates the production website in the `dist` folder. You can deploy the project to Vercel or Netlify. For Vercel, the framework preset is **Vite** and the build command is `npm run build`.

## Portfolio content accuracy

- Easy Expense Tracker is presented as deployed.
- ShopEase is marked in progress.
- Smart Public Transportation is explicitly marked as an academic project in the research/requirements phase.
- Skills are presented as a growing toolkit, not as claims of expert-level proficiency.
